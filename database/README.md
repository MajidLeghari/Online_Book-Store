# Database Directory: Online Book Store

This directory contains all database schemas, seed data, and portable/temp database artifacts for the Online Book Store project.

---

## 📁 Files Included

| File | Type | Description |
|---|---|---|
| `schema.sql` | MySQL 8/9 | Complete DDL schema and initial seed data for MySQL |
| `bookstore_db.sqlite` | SQLite / Turso | Exported portable/temp SQLite database file with all tables and data |
| `export_to_sqlite.py` | Python Script | Utility script to re-export MySQL data into SQLite format anytime |

---

## 1. Using `bookstore_db.sqlite` with Turso Cloud Database

If you want a free, serverless cloud database for your application without running a local MySQL server:

### Step 1: Install Turso CLI
```powershell
# On Windows (PowerShell)
winget install turso
# Or using Scoop
scoop install turso
```

### Step 2: Authenticate with Turso
```bash
turso auth login
```

### Step 3: Create a Database from this SQLite file
Run from the root of this project:
```bash
turso db create bookstore-db --from-file database/bookstore_db.sqlite
```

### Step 4: Get Connection Details
```bash
# Get the Database URL (e.g., libsql://bookstore-db-username.turso.io)
turso db show bookstore-db --url

# Generate an auth token
turso db tokens create bookstore-db
```

---

## 2. Using Local MySQL

If you run MySQL locally on your machine:
- **Default Database Name:** `bookstore_db`
- **Default Port:** `3306`
- **Tables auto-generated by Spring Boot Hibernate:**
  - `users`
  - `categories`
  - `books`
  - `carts`
  - `cart_items`
  - `orders`
  - `order_items`
- Or manually run `schema.sql` inside MySQL Workbench or CLI.

---

## 3. Re-exporting MySQL to SQLite

Whenever you add new data in MySQL and want to refresh `bookstore_db.sqlite`:
```bash
python database/export_to_sqlite.py
```
This updates `database/bookstore_db.sqlite` with the latest rows from your local MySQL database.
